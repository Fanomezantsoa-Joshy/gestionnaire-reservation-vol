# Gestionnaire des réservations de vol

Application desktop développée en C++ avec Qt Creator 17.0.1 (Community) et MySQL permettant de gérer les réservations de vols.

## Fonctionnalités

- Accès par authentification des utilisateurs
- Gestion des passagers
- Gestion des avions
- Gestion des compagnies aériennes
- Gestion des vols
- Gestion des réservations

## Technologies

- C++
- MySQL
- Qt Creator

## Base de données

Le projet utilise MySQL.

Le script SQL permettant de créer la base de données se trouve dans :
base_de_donnees/gestion_billets_avion.sql

## Installation

1. Installer Qt Creator (Cummunity)
2. Installer MySQL
3. Cloner le projet
4. Importer le script de la base de données dans database/gestion_billets_avion.sql
5. Ouvrir le projet avec Qt Creator
6. Compiler et exécuter
7. Un compte de teste est déjà disponnible (Nom : Admin, Mot de passe : motdepasse)
